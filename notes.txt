WHAT ACTUALLY WORKS (somehow):
- C server builds and runs on windows (flexlink with -chain mingw64, 47 system libs)
- OCaml bridge links with -linkall (without this the callbacks are NULL and everything is pain)
- SQLite DB with roles, users, sessions, SOPs, event types, permissions, view panels
- Auth system with bcrypt (vendored crypt_blowfish.c, no deps) + bearer tokens
  + open mode (no users = no login wall)
- All the CRUD API endpoints for roles, users, SOPs, event types
- Panel/permission config endpoints (GET/PUT /api/roles/*/panels and /permissions)
- WebSocket for real-time sync
- OCaml engine for incidents/units/events
- js_of_ocaml client compiles (2.6MB of javascript. normal.)
- IBM Plex Mono font (the one good decision)
